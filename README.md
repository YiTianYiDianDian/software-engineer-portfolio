# GitHub Pages Portfolio

React + Vite portfolio for a freelance Senior Software Engineer.

## 1. Install

```bash
npm install
```

## 2. Run locally

```bash
npm run dev
```

## 3. Before publishing

Edit `src/main.jsx` and replace:

- `Your Name`
- `YOUR_EMAIL@example.com`
- `YOUR_USERNAME` for GitHub
- `YOUR_USERNAME` for LinkedIn
- Project descriptions / achievements

## 4. GitHub Pages

Create a GitHub repository named:

`YOUR_USERNAME.github.io`

Then upload the project files and enable Pages from:

Settings → Pages → Deploy from a branch → main → /(root)

For the simplest GitHub Pages deployment, build the Vite app and publish the generated `dist` folder using GitHub Actions or a Pages-compatible workflow.

A ready workflow can be added if you prefer automated deployment.
